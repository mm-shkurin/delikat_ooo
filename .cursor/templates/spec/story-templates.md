# Story Spec — Delikat Templates

## Main: `NN_StoryName.md` (~50 lines max)

```markdown
# [Story Title]

## Brief Description
[1-2 sentences]

## Flow
[Numbered steps, max 10]

## Acceptance Criteria
[Bullets — what must work]

## Validation Rules
| Field / State | Rule |
|---------------|------|

## Screen States
[Distinct screens/states in site/]

## Core Requirements
[Actionable bullets only]
```

Rules: no warnings, no nice-to-haves, no fluff in the main file.

## Notes: `NN_StoryName_Notes.md`

```markdown
# [Story Title] - Notes

## Warnings
### Functional
### UI/UX
### Technical

## Suggestions & Future
### Functional
### UI/UX
### Technical

## Technical Notes
### Assets
### Responsive
### Accessibility
### Brand constraints
```
