# Delivery — story 15

### 2026-11-15 — staff orders live end-to-end
- Type: decision
- Note: `/admin/orders` lists every shop order once and PATCHes status through `StaffOrdersService`. Checkout resolves buyer via optional Bearer before idempotent create; guest is «Гость». Receipt / `OrderCreated` never include `buyer_name` or `buyer_email`. Migration `0008_order_buyer_snapshot` adds the two columns.

### 2026-11-15 — OneDrive still blocks compose build
- Type: quirk
- Note: `docker compose up -d --build` fails with `invalid file request` on Dockerfiles and fixtures while the repo lives under OneDrive reparse points. Workaround that worked: robocopy backend + examples to `%TEMP%`, `docker build` there, then `compose up -d --no-build --force-recreate backend frontend`.

### 2026-11-15 — checkout Authorization only when signed in
- Type: invariant
- Note: `createOrder` sets `bearer: Boolean(currentSession()?.accessToken)`. A dead Bearer must 401 and must not fall through to a guest POST. Cart error copy for that case is «Сессия истекла. Войдите заново.»
