# Delivery — story 17

### 2026-11-15 — live socket is not an OpenAPI path
- Type: quirk
- Note: `check_api_contract.py` only reads `paths`. The frame stays under `x-websocket` in `store_api.yaml`. The client URL is the constant `CATALOG_LIVE_PATH` in `useCatalogLive.js`, not a template in `paths.js`. Vite proxy needs `ws: true`. The dev gateway maps `$http_upgrade` to `Connection` so `/api/` can upgrade.

### 2026-11-15 — buyer category filter is existence, not the seed set
- Type: decision
- Note: `CatalogService` rejects `category_id` when `category_exists` is false (`400 validation_error`). `VALID_CATEGORIES` is no longer the gate. Fakes that implement `CatalogRepository` need `category_exists`. A category that only has hidden SKUs still exists. Staff patch/delete of a missing category is `404 category_not_found` with «Категория не найдена.» Product-write `CategoryNotFound` stays 400.

### 2026-11-15 — signal refresh must not abort itself
- Type: quirk
- Note: On `catalog_changed` the feed loads categories, then products with `limit = max(16, shown) ≤ 100`. If the selected id is gone, or that product GET is 400, the filter becomes «Все» and the list is read again without `category_id`. `skip` stops the filter effect from aborting that in-flight pair. The open product panel is left alone. A price edit does not publish the frame.

### 2026-11-15 — OneDrive still blocks compose build
- Type: quirk
- Note: `docker compose up -d --build` from `infra/` fails with `invalid file request` on OneDrive reparse points. The backend image was built from a temp copy of the context, then `compose up -d --no-build --force-recreate backend`. Frontend is bind-mounted; `compose restart frontend` picks up Vite config, including the websocket proxy. Gateway was restarted so the upgrade headers load.
