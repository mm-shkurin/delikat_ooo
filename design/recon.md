# Recon map: городская витрина кухни (web)

Scope: одна публичная страница кухни в городе — каталог, выбор способа получения, адрес, карточка с добавками, корзина. Не весь сайт и не приложение.
For: свой макет «Деликат» в этом репозитории.
Date: 2026-10-28

Источник смотрели как посетитель: открытая страница, клик по блюду с ценой «от», клик по корзине. Исходный код, запросы сети и чужие файлы не сохранялись.

## Flows

```
F01 Собрать заказ на доставку
    S01 -> S02 -> S03 -> S02 -> S04
    happy path clicks: 5 (блюдо, адрес, сохранить, в корзину, корзина)
    edge: адреса нет, добавка меняет сумму, раздел пуст после поиска, самовывоз вместо доставки

F02 Найти раздел
    S01 лента разделов прокручивает к заголовку
    happy path clicks: 1
    edge: поиск не находит ничего
```

## Inferred data model

```
City        name
            evidence: чип «Омск» на S01
            confidence: high

Address     city, line
            evidence: пустой адрес блокирует добавление на S02
            confidence: high

Category    name, order
            evidence: горизонтальная лента на S01
            confidence: high

Dish        name, weight, price, price_from, compare_at, rating, category
            evidence: карточки S01
            confidence: high

Extra       name, price
            evidence: сетка на S02
            confidence: high

CartLine    dish, extras, exclusions, qty
            evidence: кнопка «в корзину» на S02, иконка корзины на S01
            confidence: medium
```

Relationships: Category 1-n Dish, Dish 1-n Extra, Cart 1-n CartLine.
